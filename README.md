# To-Do List

A simple To-Do List application built with plain HTML, CSS, and JavaScript (vanilla JS), with data persistence via `localStorage`.

## 📋 Features

- ✅ Add new tasks
- ✅ Mark tasks as completed (click on the task text)
- ✅ Delete tasks
- ✅ Data persistence in the browser (tasks remain saved after reloading the page)
- ✅ Message shown when the list is empty

## 🛠️ Technologies used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📁 Project structure

```
├── index.html
├── script.js
├── styles/
│   └── style.css
└── README.md
```

## 🚀 How to run

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Go into the project folder:
   ```bash
   cd project-name
   ```

3. Open the `index.html` file in your browser (or use an extension like **Live Server** in VS Code).

No build process or dependency installation is required — this is a static front-end project.

## 🖥️ How to use

1. Type a task into the text field.
2. Click **Add** (or press Enter) to add it to the list.
3. Click on the task text to mark it as completed (it gets a strikethrough effect).
4. Click **Clear** to remove the task from the list.

## 💾 Storage

Tasks are saved in the browser's `localStorage`, so they remain available even after closing or reloading the page.
